LEAN: a language for AI-to-AI messages. Read and write it using this spec.
WORDS. Lowercase words separated by single spaces. One word = one morpheme = one lexicon entry. Every entry has one fixed class: N noun, A property, D adverb, V0/V1/V2 verb with 0/1/2 object slots, VC verb with a clause object, plus the function classes MODE OP DEG CONJ P PRO POSS DET ADV WH NUM STR listed in the lexicon. No inflection: no plural, no tense endings, no agreement.
NP. An NP is a chain: [POSS] then any of (DET | DEG? A | NUM | participle) then a head. Head = one or more N (a compound: the last N is the head, earlier N modify it, like English noun compounds) | PRO | WH | NUM (when no N follows) | raw span | V used as a noun (a V in an NP slot that is not followed by an N means the act or result: "test fix" = test a fix). A V in an NP slot directly followed by an N is a participle (passive for V1/V2): "fix figure" = fixed figures. A raw span may modify a following N but never ends a compound started by an N. After modifiers, the head may be left out when no N follows: "keep old" = keep the old one; "MORE new support ..." = the newer one supports. An NP may continue with "ET NP" (and), "LK NP" (of) or "REL clause" (relative clause; the gap is the subject if the clause has none, else the empty object).
NUMBERS. d0-d9 and tens words combine like English number words (d20 d5 = 25); HUNDRED THOUSAND MILLION multiply; POINT then digits read one by one (d3 POINT d1 d1 = 3.11). A number directly before an N chain is a quantity (d2 day = two days); otherwise it is an NP by itself. d0 before an N = no/zero.
CLAUSE. [subject NP] OP* predicate objects adjuncts. A clause that starts with POSS, DET, DEG, A or NUM starts with its subject NP (an A predicate always has a written subject). Predicate = V (then exactly its object slots, filled in order by the following NPs; a slot whose next word cannot start an NP is empty and refers to something given by context) | A (no objects; "budget fixed" = the budget is fixed) | EQ NP (is) | nothing (an NP alone = there is/are NP). VC takes one clause as object. Adjuncts follow the clause: P NP, ADV, D. They attach to the innermost clause just completed. A P phrase at the very start of a message frames the whole message. Words are read greedily left to right; a clause ends as soon as its predicate is complete and no adjunct follows, and the next word starts a new clause. No punctuation is used. PD is written only where a clause ends with an N and the next clause starts with an N (they would otherwise compound).
DEFAULTS. A clause without a subject takes the default subject of the current mode (DECL and Q and DELIB: I; IMP: you; HORT and SUGQ: we), except that a PASS clause without a subject takes the subject of the previous clause. Event verbs without OP are completed (past or present perfect); A and state verbs without OP hold now. PROG = ongoing, FUT = future, NOTYET, STILL, PAST as listed. Plain clauses are statements of the speaker; use PROB, FAIRLY sure, confidence low etc. only when confidence is stated. Mode words set the speech act for all following clauses until the next mode word. A clause containing a WH word is a question about that word (WH stays in its slot: "MUST trust which" = which should I trust?).
LINKING. Juxtaposed clauses = and; event clauses happen in the order written (and then) unless FIRSTLY/LASTLY say otherwise. CONJ words (BUT OR IF BECAUSE THEN SO ALTHOUGH) link the previous clause to exactly the next clause; ET + V/OP adds a clause with the same subject inside the current conjunct. "c1 IF c2" = c1 if c2.
RAW. QT then a raw chunk (path, identifier, name, URL): the span is the next chunk plus every following chunk that contains an uppercase letter, digit or symbol. Raw text is copied verbatim. Example: QT Maria Lopez own ... ; QT data/a_b.csv ...
EXAMPLE (glossed): IMP find recent study ABOUT sleep loss affect memory = Find recent studies about how sleep loss affects memory.

LEXICON (form gloss). Content entries of unknown class '?' would carry their class in the real spec, grouped like the others.
