# E3 기준선: AI 메시지 코퍼스의 토큰 비용

`baseline.py` 가 만든 요약이다. 숫자는 모두 이 스크립트로 잰 값이며, 원자료는 `baseline.json` 에 있다. 코퍼스는 `corpus/ai_messages.json` (메시지 40개)다.

## 0. 요약

1. **en 기준선**: 메시지 40개 합계 1159 (llama4) ~ 1268 (mistral_sp) 토큰, o200k 기준 메시지당 평균 29.0, median 27.0, p90 41.0 토큰.
2. **en_terse (전보체, 사양 없는 최강 경쟁자)**: en 대비 합계 비율 0.73 (claude_legacy) ~ 0.76 (mistral_sp), 7개 평균 0.74. o200k 0.73, claude_legacy 0.73. en 보다 적은 메시지 비율 (o200k) 100%.
3. **ko (한국어)**: en 대비 합계 비율 1.16 (llama4) ~ 2.29 (mistral_sp), 7개 평균 1.65. o200k 1.30, claude_legacy 2.21. en 보다 적은 메시지 비율 (o200k) 0%.
4. **json (압축 JSON)**: en 대비 합계 비율 0.94 (cl100k) ~ 1.13 (mistral_sp), 7개 평균 1.00. o200k 0.97, claude_legacy 1.06. en 보다 적은 메시지 비율 (o200k) 52%.
5. **oracle_min** (메시지마다 en / en_terse / json 중 최소): en 대비 0.73 ~ 0.76, 평균 0.73. 최소값을 낸 표기 횟수 (메시지 × 토크나이저 280칸, 동률은 모두 셈): en 0, en_terse 271, json 13.
6. **탈출 대상(숫자, 경로, 식별자, URL, 고유명사)이 있는 메시지 14개 vs 없는 메시지 26개** (7개 평균 en 대비 비율): en_terse 0.77 vs 0.72, json 1.03 vs 0.98. o200k 메시지당 평균 en 토큰 32.2 vs 27.3.
7. **이 언어의 목표선**: 사양 없이 읽히는 en_terse 를 이기려면 메시지당 평균 토큰이 o200k 21.2, claude_legacy 21.4 보다 적어야 한다 (en 은 29.0 / 29.5). E2 의 W2_spaced + token_picked 토큰/형태소로 환산하면 메시지당 형태소 o200k 21.0개, claude_legacy 19.0개 미만이다 (7절). 사양(수천 토큰)을 컨텍스트에 넣는 비용은 이 비교에 들어 있지 않다.

작성 방침

- 네 표기는 같은 정보를 담는다. 작은 수는 en 에서 낱말(five)로, en_terse 와 json 에서는 숫자로 적었다.
- en_terse 는 관사·계사를 빼고 `->`, `=`, `+`, `~`, `;` 같은 기호를 쓴다. 약어는 토크나이저로 재 보고 토큰을 늘리지 않을 때만 남겼다 (예: `w/`, `Ctx`, `2nd`, `O(n^2)` 는 `with`, `Context`, `second`, `quadratic` 보다 토큰이 많아 쓰지 않았다).
- json 은 짧은 키, 공백 없는 직렬화(`separators=(',', ':')`), 값은 대부분 snake_case 다. 고유명사와 URL 은 원문 그대로 둔다.
- ko 는 자연스러운 한국어다. 외국 인명·지명은 한글로 옮겼고, 경로·식별자·URL 은 원문 그대로 둔다.
- 실존 서비스 URL 은 Python 문서 하나뿐이고, 나머지 이름(인물, 저장소 example-org/tilemap)은 가상이다.

## 8. 한계

- 코퍼스는 한 모델이 한 번에 쓴 40개 메시지다. 문체가 한쪽으로 치우쳤을 수 있고, 표본이 작아 비율의 소수 둘째 자리는 믿기 어렵다.
- 네 표기가 정말 같은 정보를 담는지는 작성자가 맞췄을 뿐 사람이나 다른 모델이 검증하지 않았다. en_terse 가 사양 없이 정확히 이해되는지도 모델 API 없이 확인할 수 없어 재지 않았다.
- 현행 Claude 토크나이저는 공개되지 않았다. claude_legacy 는 대용 지표다.
- en_terse 의 약어 선택은 이 토크나이저들로 재 보며 골랐으므로 경쟁자에게 유리한 쪽으로 치우쳐 있다 (의도한 것이다).
- json 은 짧은 키와 snake_case 값을 쓴 비교적 압축된 형태다. 실제 에이전트 사이 JSON 은 키가 더 길거나 공백이 들어가 더 비쌀 수 있다.
- 탈출 대상 판정은 휴리스틱이다. 전부 대문자인 약어는 세지 않는다.
- 채팅 템플릿, 역할 표지 같은 메시지 부가 토큰과 사양(컨텍스트) 비용은 세지 않았다.
