# lang_for_ai

사람은 읽기 어렵고 AI는 읽고 쓸 수 있는 새로운 언어를 설계하는 프로젝트입니다. 문자는 로마자 알파벳만 씁니다.

> **작업 정의**: 사양 없이는 사람이 의미를 추측할 수 없고, 사양이 있어도 사람이 실시간으로 읽고 쓰기는 매우 어렵지만,
> LLM은 사양을 컨텍스트로 받으면 곧바로 정확하게 읽고 쓸 수 있는 언어.
>
> 이 언어는 난독화이지 암호가 아닙니다. 기밀 보호 수단으로 쓰지 마세요.

## 설계 진행 현황

| 계층 | 상태 | 현재 방향 |
|---|---|---|
| 목적 | 확정 (D-002~D-005) | AI 간 통신, 토큰 절약(일반 영어보다 싸면 충분), 실험. 사양은 컨텍스트로 제공. 사양 없이 못 읽으면 충분 |
| L0 문자 집합 | 확정 (D-007) | 소문자 a–z + 단어 사이 공백 하나 |
| L1 형태소 모양 | 확정 (D-007) | 단어 하나 = 형태소 하나. 토크나이저 어휘를 훑어 1토큰이면서 단어가 아닌 형태를 고른다 |
| L2 형태론 | 확정 (D-007) | 분석어 (굴절 없음). 1단계의 교착어 제안은 철회 |
| L3 어휘 | 미정 | 어휘 약 2,300개 규모에서 Claude가 읽을 수 있음을 확인. 품사 체계는 다음 단계 |
| L4 통사론 | 방향 확정 (D-007) | 어순으로 역할 표시 (주어-동사-목적어). 세부 문법은 다음 단계 |
| L5 화용 | 방향 확정 (D-007) | 확신도·증거성·화행은 기본값이 아닐 때만 표시 |
| L6 난독화 | 만들지 않음 (D-004) | — |
