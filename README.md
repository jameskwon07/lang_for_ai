# lang_for_ai

사람은 읽기 어렵고 AI는 읽고 쓸 수 있는 새로운 언어를 설계하는 프로젝트입니다. 문자는 로마자 알파벳만 씁니다.

> **작업 정의**: 사양 없이는 사람이 의미를 추측할 수 없고, 사양이 있어도 사람이 실시간으로 읽고 쓰기는 매우 어렵지만,
> LLM은 사양을 컨텍스트로 받으면 곧바로 정확하게 읽고 쓸 수 있는 언어.
>
> 이 언어는 난독화이지 암호가 아닙니다. 기밀 보호 수단으로 쓰지 마세요.

## 설계 진행 현황

| 계층 | 상태 | 현재 방향 |
|---|---|---|
| 목적 | 미정 | 결정 필요 (AI 간 통신 / 토큰 압축 / 사람에게 숨기기 / 실험) |
| L0 문자 집합 | 제안 | 소문자 a–z, 공백 사용 여부는 실험으로 결정 |
| L1 형태소 모양 | 제안 | 어근 CVC + 접사 VC, 글자 모양으로 분절 |
| L2 형태론 | 제안 | 교착어 (접사 하나 = 의미 하나) |
| L3 어휘 | 제안 | 핵심 어근 무작위 배정 + 파생 접사 |
| L4 통사론 | 제안 | 술어 먼저 + 격 표시 + 절 경계 표지 |
| L5 화용 | 제안 | 확신도, 증거성, 화행을 필수 표시 |
| L6 난독화 | 보류 | 목적 확정 후 결정 |
